# Security Policy

## Supported Versions

Security fixes are applied to the latest version on the default branch. Experimental releases may contain bugs and are not recommended for exposing ComfyUI to a network.

## Reporting a Vulnerability

Please do not publish credentials, tokens, private prompts, source images or generated videos in a public issue.

Use GitHub's Report a vulnerability feature for this repository when available. Include affected commit/version, impact, reproduction steps and a minimal redacted proof of concept. Do not include model weights or private media.

The pause/resume API is intended for the local ComfyUI frontend. Do not expose the ComfyUI server or these endpoints to untrusted networks.
